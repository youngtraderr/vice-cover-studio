Vice Cover Studio — turn a photo + caption into GTA 6-style cover art: multi-panel poster layouts, Vice City sunset/neon grades, bold Anton lettering with a halftone title block. Exports PNG in 1080x1080, 1080x1350 and 1920x1080, fully offline from static files.

## Run it

```sh
Open app/index.html in a desktop browser, load a photo, pick a layout and grade, edit the caption, and export PNG.
```
